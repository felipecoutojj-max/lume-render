# Lume Render

Render realista de esculturas feitas no ZBrush (OBJ, PLY, STL), feito para o iPad.

**Abrir:** https://felipecoutojj-max.github.io/lume-render/

## Instalar no iPad
1. Abra o endereço acima no **Safari**.
2. Toque em **Compartilhar** e depois em **Adicionar à Tela de Início**.
3. Abra o Lume pelo ícone: ele roda em tela cheia e funciona sem internet.

As esculturas são abertas direto do iPad e não são enviadas para nenhum servidor.

## Versões
- `index.html`: versão atual (v3, iPad instalável)
- `versoes/`: versões anteriores (Mac v2, iPad v1)

Usa three.js r128 (licença MIT, em `vendor/`).
